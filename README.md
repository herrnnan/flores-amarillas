## 🌻 ¿Qué es?

> Cada **21 de septiembre**, en Argentina, se regalan flores amarillas. Es el inicio de la primavera en el hemisferio sur, y una tradición que se hizo famosa gracias a *Floricienta*.

La armé para que puedas regalar ese ramo de forma virtual. Escribís el nombre de la persona, se genera un link único y se lo mandás. Cuando lo abre, suena la música y un ramo de flores amarillas florece en 3D para esa persona especial.

- 🎁 **Gratis y sin cuenta:** no tenés que registrarte ni instalar nada.
- 📱 **Pensado para el celular:** se ve y anda bien en teléfonos nuevos y viejitos.
- 🔒 **Sin datos guardados:** el nombre viaja solo dentro del link. No hay base de datos ni nada que se guarde.

---

## ✨ Cómo se usa

1. ✍️ **Escribí su nombre.** Si querés, también el tuyo en "De parte de".
2. 🔗 **Tocá "Crear el link".**
3. 📲 **Mandáselo** por WhatsApp, Instagram o donde quieras. Con el botón "Compartir" sale directo.
4. 🎶 **Cuando lo abra**, toca "Abrir", arranca la música y empieza el show.

> 💡 Tip: decile que suba el volumen antes de abrirlo.

---

## 💛 Qué va a ver

- 🌾 Un campo de girasoles al atardecer, con el pasto moviéndose con el viento.
- 💐 Un ramo envuelto en papel kraft que baja girando hasta un frasco de vidrio sobre un tronco.
- 🌼 Las flores del ramo brotando de a una, desde el centro hacia afuera, hasta abrirse por completo.
- ✨ Un destello dorado cuando el ramo termina de abrirse, con pétalos que caen y polen flotando en la luz.
- 💌 Su nombre escrito a mano y tu mensaje de primavera.

## 🛠️ Con qué está hecho

Todo lo que ves es 3D generado en el momento: no hay fotos ni videos. Cada pétalo, tallo y hoja de pasto lo dibujé con código.

![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)
![Three.js](https://img.shields.io/badge/Three.js-000000?style=for-the-badge&logo=threedotjs&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-06B6D4?style=for-the-badge&logo=tailwindcss&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

- ⚛️ **React:** arma las pantallas (el menú y el regalo).
- 🧊 **Three.js + React Three Fiber:** el mundo 3D, con flores, luz, cielo y cámara.
- 🎨 **Tailwind CSS:** el diseño de textos, tarjetas y botones.
- ⚡ **Vite:** hace que la web cargue rápido.

<summary><b>💻 ¿Querés correrlo en tu compu?</b></summary>

```bash
npm install
npm run dev
```

Para generar la versión final (una web estática que podés subir a Vercel, Netlify o GitHub Pages):

```bash
npm run build
```
